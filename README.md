# download_speed.py — замер скорости скачивания

Консольный скрипт на Python 3 (только стандартная библиотека, ничего устанавливать не нужно).
Делает 10 последовательных запросов к указанному адресу, каждый раз дожидается полного ответа
(тело читается до конца), и печатает среднее время запроса, общий объём и скорость скачивания.

## Запуск

```bash
python3 download_speed.py <URL>
```

Пример:

```bash
python3 download_speed.py https://proof.ovh.net/files/10Mb.dat
```

Некоторые сайты (например, Wikimedia) отвечают скриптам `429 Too Many Requests` —
для замера лучше брать файлы, которые специально выложены для тестов скорости.

Опции:

| Опция | По умолчанию | Что делает |
|---|---|---|
| `-n`, `--count` | `10` | сколько запросов сделать |
| `-t`, `--timeout` | `60` | таймаут одного запроса, секунды |

Пример вывода:

```
URL: https://proof.ovh.net/files/10Mb.dat
Запросов: 10

# 1  HTTP 200     10.486 МБ     0.820 с     102.24 Мбит/с
# 2  HTTP 200     10.486 МБ     0.617 с     135.94 Мбит/с
...
#10  HTTP 200     10.486 МБ     0.705 с     118.99 Мбит/с

Среднее время запроса: 0.719 с
Всего скачано:         104.858 МБ (104857600 байт)
Скорость скачивания:   116.62 Мбит/с (14.58 МБ/с)
```

## Единицы измерения

- **Время** — секунды (`с`).
- **Объём** — мегабайты, **1 МБ = 1 000 000 байт** (десятичные, не MiB). В итоге дополнительно
  печатается точное число байт.
- **Скорость** — основная единица **Мбит/с, 1 Мбит = 1 000 000 бит**: так же меряют провайдеры
  и спидтесты, удобно сравнивать с тарифом. В скобках та же скорость в **МБ/с** (1 МБ/с = 8 Мбит/с) —
  так её показывают браузеры и менеджеры загрузок.

## Как считается

- **Время запроса** — от начала запроса (включая DNS, TCP/TLS-рукопожатие и ожидание первого байта)
  до получения последнего байта тела ответа.
- **Среднее время** = сумма времён всех запросов / число запросов.
- **Общий объём** — сумма байт тела ответа по всем запросам (заголовки не считаются).
- **Скорость** = общий объём / суммарное время всех запросов.

Поскольку во время входят задержки на установку соединения, на маленьких файлах скорость получится
заниженной — для осмысленного замера берите файл от нескольких мегабайт.

## Ошибки

Если любой запрос завершился ошибкой (HTTP 4xx/5xx, таймаут, обрыв соединения, неполный ответ),
скрипт печатает причину и выходит с кодом `1` — результат на неполной выборке не выводится.
Ctrl+C прерывает замер (код `130`).

## Тесты

Тесты написаны на `unittest` из стандартной библиотеки. Они поднимают свой локальный HTTP-сервер
и в интернет не ходят. Запуск из корня проекта:

```bash
python3 -m unittest -v
```

Если установлен pytest, можно запускать и через `pytest`.
